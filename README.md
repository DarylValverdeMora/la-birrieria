# La Birrieria — landing (prototipo frontend)

Sitio estático: HTML + CSS + JS vanilla. Sin build.

- `index.html` — estructura
- `css/styles.css` — tokens de marca arriba (colores y fuentes)
- `js/data.js` — TODO el contenido editable: contacto, horario, menú y precios
- `js/app.js` — menú interactivo, pedido por WhatsApp, estado abierto/cerrado
- `assets/` — logo y fotos (WebP)

Buscá `[PLACEHOLDER]` para ver lo que falta confirmar con el dueño.

## Correr local
    python3 -m http.server 8080   # o: npx serve .

## Publicar
Subilo a su repo de GitHub e importalo en Vercel (framework: Other, sin build command).
